# Results

- `tables/` contains aggregate model metrics, target/feature summaries, tuning records and report-ready diagnostics.
- `figures/` contains figures regenerated by the executed notebooks.
- `predictions/` contains local row-level out-of-fold and secondary-analysis predictions used to derive aggregate outputs; these files are ignored by Git.
- `logs/` is a local execution directory and is ignored by Git.

The report-ready tables and figures can be regenerated from the source dataset by running `python run_all.py`.
